# Running-Tracker-App

###  나의 러닝 기록을 관리할 수 있는 토이 프로젝트

> 프로젝트 기간 : 2025/10/16 ~ 2025/10/22

> URL : https://running-tracker-app-ten.vercel.app/


## 🎯 구현 목표
- CRUD 기능 (추가, 조회, 수정, 삭제)
- 기록 정렬 기능 (날짜, 총 거리, 러닝, 워킹, 휴식 순)
- LocalStorage를 통한 데이터 저장
